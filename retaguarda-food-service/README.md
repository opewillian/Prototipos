# Retaguarda Food Service

Protótipo de um sistema de retaguarda para operações de lojas de food service.

## Status

Em estruturação. Esta pasta reserva o espaço do primeiro protótipo no repositório `Prototipos`.

- Protótipo com dados fictícios até a definição de integrações.
