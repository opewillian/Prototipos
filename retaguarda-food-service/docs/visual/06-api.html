API

Não existe servidor próprio: o app usa a API REST do Supabase pelo supabase-js, funções RPC do Postgres e a Edge Function degust. Por fora, Linx Degust, Cloudflare R2 e ANAC.

Edge Function degust

POST JSON { "acao": "...", ... } para /functions/v1/degust, com o token da sessão. Roda no servidor; as senhas da Linx e do R2 nunca vão ao navegador.

Regras de valores (iguais às da tela)

  • Vendas canceladas ficam fora dos valores.
  • Bruto = valProduto + valDescontoItem.
  • Descontos = valDesconto + valDescontoItem.
  • Líquido = valLiquido (bate com a soma dos pagamentos).

APIs externas

Linx Degust One

Login em /api/usuario/autenticar devolve token de 4 h (guardado em integration_tokens, um por franquia). Relatório de vendas até 30 dias por chamada, pela data do caixa. Franquias: DEL (segredo), SAL 2168, ACB 2642, BIT 2202.

Cloudflare R2

API compatível com S3 (assinatura SigV4) chamada só pela função. Bucket retaguarda-vendas.

ANAC

Arquivo público de dados estatísticos; soma de passageiros pagos por origem (embarque) e destino (desembarque). Carga por SQL, sem API.

Erros

No app

Erros do Supabase passam por errorMessage() (ui.js) e viram texto em português no toast ou junto do campo. Têm tradução própria: sem permissão (RLS), registro duplicado, vínculo com outros documentos, sem conexão e sessão expirada.

Na função

Responde { erro: "..." } com status HTTP (400, 401, 403, 500). Falha de uma quinzena na fila marca a tarefa com erro para reenfileirar; tarefa parada há 15 min volta para a fila.
